{{- /* Imported (HTML) posts: tools/import_wp.py turned the TeX of the old posts into marker elements … / … (text only, escaped). Here they become MathML at BUILD time with Hugo's built-in KaTeX - no client-side JavaScript (the old site loaded MathJax from a CDN). Only these exact markers are touched; the marker classes cannot come from the original posts (they are not in the importer's allowlist) and raw HTML is disabled in Markdown, so nothing else in the page is rewritten. Markdown posts use layouts/_default/_markup/render-passthrough.html instead. Input: an HTML string (.Content or .Summary). Output: HTML. */ -}} {{- $c := string . -}} {{- range findRESubmatch `([^<]*)` $c -}} {{- $tex := index . 2 | htmlUnescape -}} {{- $m := transform.ToMath $tex (dict "displayMode" (eq (index . 1) "display") "output" "mathml" "throwOnError" true) -}} {{- $c = replace $c (index . 0) (string $m) -}} {{- end -}} {{- $c | safeHTML -}}
